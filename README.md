# EuroMarket Hub 🇪🇺✈️

A modern, lightweight mobile application designed for professionals planning their career relocation to Europe. This app helps users track relocation expenses (visas, flights, accommodation) and monitor European job opportunities in one centralized place.

---

## 🚀 Project Purpose & Motivation

This project is part of a high-performance study roadmap tailored to meet the technical standards of the European tech market. The core focus is to implement clean architecture, strict typing, state management, and optimized performance using a mobile-first approach.

To keep development highly efficient and resource-friendly, the project leverages **Expo Go** connected directly to physical devices, bypassing heavy emulators.

---

## 🛠️ Tech Stack & Architecture

- **Framework:** React Native (Expo Workflow)
- **Language:** TypeScript (Strict typing for robust code)
- **Navigation:** Expo Router (File-based routing system)
- **State Management:** React Hooks (`useState`, `useMemo`)
- **Styling:** React Native `StyleSheet`

### Core Concepts Implemented (So far):

- **Domain-Driven Types:** Strict interfaces for Expenses and Jobs to prevent runtime bugs.
- **Unidirectional Data Flow:** Dynamic state rendering with optimized component re-renders.

---

## 📱 Current Features

- [x] **Relocation Expense Dashboard:** List of essential moving costs with custom categories.
- [x] **Interactive Status Toggle:** One-tap interaction to change expense status (Paid/Pending) instantly.
- [x] **Lightweight Architecture:** Structured `src/` folder isolating components, mock data, and types.
- [ ] **Automated Budget Calculation:** (In progress) Live budget tracking using memory optimization hooks.

## ⚙️ How to Run the Project Locally

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine and the **Expo Go** app installed on your physical Android or iOS device.

1. Clone this repository:
